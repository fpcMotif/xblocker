## Findings considered and rejected

- Bulk pacing (250 ms between accounts, act then confirm per account): decided in `docs/adr/0004-bulk-confirm-and-retry.md`. Not a finding.
- No authentication on the Convex functions: a documented choice in `convex/README.md`. Not a finding on its own. It blocks the Convex half of plan 011.
- Lost updates between extension contexts on the blocked list: documented as self-healing in `packages/storage/blocked-store.ts:147-167`. Plan 005 narrows the window to a single account key.
- Export revokes its object URL in the same tick as the click (`entrypoints/options/download.ts:14-16`): no observed failure; low confidence.
- Virtual list measures a detached container at mount (`entrypoints/options/main.ts:247-250`): no visible symptom with today's constants.
- Pretty-printed export JSON: changing it alters the export file's formatting for a small gain.
- Whitelist import cap of 10,000 handles (`entrypoints/options/panes/whitelist.ts:26`): a product limit for the owner to set; raise it only together with a file-size check.
- Slider in the General pane writes storage on every input event (`entrypoints/options/panes/general.ts:150`): real but minor; not selected.
- Delta cloud pull (an `updatedAt` index in Convex): the largest remaining sync cost after these plans. Deferred because row deletions need a tombstone design first.
- `docs/adr/0003-sync-policy-and-cloud-adapter.md` names old file paths and says `clearCloud` is module-private while `packages/sync/lib/convex-sync.ts:144` exports it: stale documentation, reported to the owner, not planned.
